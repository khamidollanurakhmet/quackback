# Assets

## stand_in_person.png

The person the duck looks for in the simulator: a cutout of "Man standing on a road" by Mohammad
Faruque, https://stocksnap.io/photo/people-guy-5IQZXUH5X6, released under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/), as the photo page and StockSnap's terms
stated on 2026-10-26. Cut out from the 960 px version with MediaPipe's pose segmentation mask and
cropped to the person. Used only as a stand-in in a simulated scene; the person shown endorses
nothing.

Set `QUACKBACK_SANDBOX_PERSON_IMAGE` to a PNG of your own (ideally with a transparent background)
to put someone else there.
